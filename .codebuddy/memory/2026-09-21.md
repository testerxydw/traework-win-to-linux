# 2026-09-21

## 图标生成失败修复（本机缺 convert → deb 零图标）

### 现象
用户跑 `bash build.sh` 输出：

```text
>>> 生成图标 ...
  [警告] 缺少 ImageMagick (convert)，跳过图标生成（apt install imagemagick）
```

产物 `trae-solo-cn_0.1.67-1_amd64.deb` 包内 `share/icons` 文件数 = **0**（桌面/菜单无图标）。

### 根因
本机只装了 `imagemagick-7-common`（8:7.1.2.27，**配置文件包**），**没有 ImageMagick 主程序** →
`convert` 与 `magick` 都不存在；`rsvg-convert`（已装 2.58.0）只能处理 SVG；PIL 未安装。
旧脚本 `elif ! command -v convert` → **整段跳过**图标生成。
（注意：图标素材 `trae-icon-256.png`（256×256）一直是有的，缺的是缩放工具。）

### 修复（`build.sh`，commit `ab7f975`）
缩放工具按可用性回退：`convert` → `magick` → **`ffmpeg`** → 原图复制兜底，
并在日志打印实际使用的工具：

```text
>>>   已生成 7 个尺寸 + scalable（缩放工具: ffmpeg）
```

（`workbuddy-win-to-linux/build.sh` 早有"无 convert 则复制原图"兜底，只是尺寸不精确；trae 原本**没有**任何兜底。）

### 验证
重跑 `bash build.sh --no-install --skip-extract` → 产出 `trae-solo-cn_0.1.67-2_amd64.deb`（251M），
包内 8 个 PNG：`16/32/48/64/128/256/512x*/apps/trae-solo-cn.png` + `scalable/apps/...`，
大小 454B → 31KB 递增 → 证明是**真缩放**而非同图复制。
同时提交 `deb-pkg/DEBIAN/control`（版本自增 0.1.67-1 → 0.1.67-2）。
