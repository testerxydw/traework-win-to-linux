## 修复 Trae(deb) 无标题栏/三键
- 应用为 Electron (VS Code fork)，启动器: opt/trae-solo-cn/trae-solo-cn (真实脚本)，usr/bin/trae-solo-cn 是指向它的 symlink
- 代码分析: main.js 行180 在 Linux (Lt=isLinux) 默认 frame=!1 + titleBarStyle="custom"; getValue("window.titleBarStyle") 硬编码 custom
- 用户环境: DDE (deepin) + X11。自绘(custom)在 DDE/X11 常渲染失败，solo-lite 构建可能裁剪自绘 titlebar UI
- 最终方案: 用户选择原生系统标题栏 `--title-bar-style=native`（DDE 接管，带三键）
- 重建流程: dpkg-deb -e xxx.deb /tmp/x/DEBIAN + dpkg-deb -x xxx.deb /tmp/x; 改 opt/trae-solo-cn/trae-solo-cn 脚本; sed -i 改 Version; find . -path ./DEBIAN -prune -o -type f -print0 | xargs -0 md5sum | sed 's| ./| |' > DEBIAN/md5sums; dpkg-deb -b --root-owner-group
- 13版 native 仍无效，根因: main.js 主窗口创建处 `Lt&&(me.frame=!1,me.titleBarStyle="custom")` (Lt=isLinux) 强制无边框+自绘，覆盖命令行参数。对比 TraeCode_CN-linux-x64.deb 的 main.js 无此强制 → 系统标题栏正常
- 最终修复: 删除 main.js 中 `Lt&&(me.frame=!1,me.titleBarStyle="custom"),` 整段，对齐 TraeCode 行为；启动脚本恢复为 `exec "$ELECTRON" "$@"`
- 重建流程含 main.js 修改: 解包后改 opt/trae-solo-cn/resources/app/out/main.js (真实文件,非 symlink)，sed 删该段；重新 md5sums; 打包
- 产物: trae-solo-cn_0.1.54-14_amd64.deb (已验证 me.frame=!1 计数为0)
- 说明: TraeCode_CN-linux-x64.deb 安装于 /usr/share/trae-cn，启动器是微软原版 VS Code 脚本，无 title-bar-style 参数，Linux 默认系统标题栏
