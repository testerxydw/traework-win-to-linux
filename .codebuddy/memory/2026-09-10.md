# 2026-09-10

## navicat 打包版清理
- 本次会话早些时候用 Appimage2Deb 打包了 navicat：`cn.com.navicat.premium.lite.time` (17.3.7)，装在 `/opt/apps/cn.com.navicat.premium.lite.time`。
- 用户要清理这个"刚打包的"版本残留，保留原版 navicat（`/opt/apps/com.navicat.premiumlite`，非 dpkg 包，仅含 entries 目录）与所有 trae（trae-cn / trae-solo-cn）。
- 已清理：`/tmp/Navicat.NkV52l`、`/tmp/Navicat.Tm3Hfq`、`/tmp/Navicat Premium Lite0`（属主为当前用户，无需 sudo）。
- 未执行（需 sudo 且审批弹窗超时）：`sudo dpkg -r cn.com.navicat.premium.lite.time` 及 `sudo rm -rf /opt/apps/cn.com.navicat.premium.lite.time`，已把命令交给用户手动跑。
- 注意：`~/.config/navicat` 是 navicat 共享配置（原版与打包版共用），清理打包版时**不要删**，否则会连原版设置一起丢。

## 环境注意
- 本环境 `sudo`/破坏性命令的审批弹窗经常无响应（超时），导致需 root 的操作无法代执行，应改为提供手动命令给用户。
