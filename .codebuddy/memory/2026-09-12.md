# 2026-09-12

## 修复 trae build.sh 打包中断（deb-pkg 打包元数据缺失）
- 现象：`bash build.sh` 在阶段 3 警告「未找到 usr/share/applications/trae-solo-cn.desktop」；
  阶段 4 `chmod: 无法访问 deb-pkg/DEBIAN/prerm / postrm`，随后脚本静默退出（`set -e` 生效），**deb 未产出**。
- 根因：commit `ad81296`（chore: 删除 deb-pkg 打包目录及相关文件）把 control/postinst/prerm/postrm、
  `usr/bin/trae-solo-cn` 软链、desktop 文件全部移出版本控制，但 build.sh 只会「追加」不会「创建」，
  于是 chmod 撞上不存在的文件即中断。
- 修复（build.sh）：
  1. 新增 `ensure_deb_meta()`，在 `stage_desktop` 开头调用：幂等地补齐 DEBIAN/control（Version 取 manifest.appVersion）、
     postinst 基础体、prerm、postrm、`usr/share/applications/trae-solo-cn.desktop`、
     `usr/bin/trae-solo-cn -> /opt/trae-solo-cn/trae-solo-cn`；已存在则不覆盖。
  2. `stage_deb` 的 `chmod 755 postinst prerm postrm` 改为逐个判存在，缺失只警告不中断。
- 验证：`bash build.sh --skip-extract --no-install --no-slim` 通过，产出 `trae-solo-cn_0.1.64-2_amd64.deb` (274M)；
  `dpkg-deb --ctrl-tarfile` 确认 postinst/postrm/prerm 均为 755，data 内含 desktop 文件与 /usr/bin 软链。
- 待办：系统内当前安装的是 0.1.63-3，需用户手动安装新包：
  `sudo dpkg -i /home/ub24/文档/script/traework-linux/traework-win-to-linux/trae-solo-cn_0.1.64-2_amd64.deb`
